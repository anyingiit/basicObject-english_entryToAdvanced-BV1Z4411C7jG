## 关于本项目

本仓库收录了 anyingiit 在 B 站观看一门英语语法课程（视频号 BV1Z4411C7jG）时整理的个人笔记，内容是把该课程自己的课件重新整理成仓库根目录下的一个 Markdown 文件；由于该文件名是中文，下方「使用方法」一节用代码块展示了它的文件名。笔记完整地沿用了课程自己的框架——十种词性、九种句子成分、八种句型——从入门讲到高级，每个知识点都配有一张指向原视频对应课件的图片链接。课件内容的原作者信息记录在该文件自己的开头；本仓库只是对其做了重新整理。

参见[未解决的问题](https://github.com/anyingiit/basicObject-english_entryToAdvanced-BV1Z4411C7jG/issues)，了解计划中的功能和已知问题。

## 开始使用

### 前置条件

- 一个能查看 Markdown 的工具，或者直接使用 GitHub 自带的渲染来阅读笔记文件——不需要编译器、运行时或包管理器。
- 能访问互联网以加载笔记中引用的课件截图，因为这些图片是外部托管的，并没有提交到本仓库里。

### 安装

这里没有任何东西需要安装——本仓库是笔记，不是一个软件包。获取本地副本：

```sh
git clone https://github.com/anyingiit/basicObject-english_entryToAdvanced-BV1Z4411C7jG.git
```

然后用 Markdown 查看器打开笔记文件（见下方「使用方法」），或者直接在 GitHub 上阅读。

## 使用方法

打开仓库根目录下的笔记文件，因为文件名是中文，这里用代码块展示：

```
英语语法-从入门到高级.md
```

按标题顺序浏览：笔记先给出课程整体的语法框架，然后逐一讲解每一种词性、每一种句子成分、每一种句型，从入门到高级。
